# Launch checklist

## Completed

- Source HTML, sitemaps, public WordPress content and full media library audited.
- Original business content and migration decisions recorded.
- 54 assets migrated to Sanity; three unrelated agency assets excluded.
- Original useful page URLs preserved; four legacy aliases mapped with 301 redirects.
- Genuine service content, team details, FAQ content and legal pages migrated.
- No fictional projects or testimonials seeded.
- Responsive public website and constrained Sanity Studio built.
- Thirteen public pages tested with axe, one H1 each, no missing alt text, no source-host image dependencies.
- No broken internal links or images in the completed local audit.
- No horizontal overflow at 320, 375, 768, 1024 and 1440 pixels.
- Keyboard menu, Escape close and FAQ interaction tested.
- TypeScript checks and production build pass.
- Ten server security checks pass, with no live email sent and no enquiry stored.
- Viewer token and HMAC preview secret stored as encrypted Cloudflare settings following explicit owner approval.

## Before replacing the existing domain

- Complete admin Sanity sign-in and connect the automatic publishing webhook.
- Verify authenticated draft preview and a real publish-to-deploy cycle.
- Supply an email delivery provider and approved sender before enabling online submission.
- Review final legal policies, image rights and any optional business claims.
- Approve verified case-study details before adding named projects.
- Confirm custom domain and canonical URLs, then rebuild.
- Recheck redirects, sitemap and structured data on the approved domain.
- Run production Lighthouse and device checks. Local Lighthouse is not a field measurement; compression and network conditions differ.
- Supply analytics and Search Console IDs if these services are wanted.

The form intentionally remains disabled until email and abuse-protection configuration is complete. Email and phone links provide the contact path. No submission database is used.
